# Stack tecnológica

A stack principal será TypeScript + React + SQLite.

- TypeScript para código mais seguro e escalável.
- React para a interface do site institucional.
- SQLite para persistência inicial de dados e login administrativo.
- Design responsivo para mobile e navegadores modernos.
- Estrutura simples para evoluir com conteúdo e notícias.

Objetivo: manter a solução popular, confiável e pronta para o crescimento do portal.
