# Roadmap

## Fase 1: Fundação
- Definir a estrutura inicial do site.
- Estabelecer a identidade visual institucional.
- Criar a base da navegação principal.

## Fase 2: Conteúdo institucional
- Montar a homepage com branding e mensagens-chave.
- Definir os cursos técnicos e suas matrizes curriculares.
- Estruturar as descrições dos cursos e disciplinas.

## Fase 3: Experiência e responsividade
- Implementar o layout responsivo para mobile e desktop.
- Validar a legibilidade e a usabilidade das páginas.
- Ajustar detalhes visuais para uma experiência mais atraente.

## Fase 4: Gestão de conteúdo
- Criar o login para gestão de notícias.
- Integrar o banco SQLite para persistência inicial.
- Publicar o conteúdo inicial do site.

## Fase 5: Validação e refinamento
- Validar a navegação e a experiência geral.
- Revisar acessibilidade e consistência visual.
- Finalizar ajustes para entrega da versão inicial.
